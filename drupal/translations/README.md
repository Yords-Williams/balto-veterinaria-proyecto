# Traducciones al español

Copias comprimidas de traducciones comunitarias oficiales, descargadas del servidor de Drupal:

- [Drupal core 11.4.12](https://ftp.drupal.org/files/translations/all/drupal/drupal-11.4.12.es.po).
- [Drupal Commerce 3.3.14](https://ftp.drupal.org/files/translations/all/commerce/commerce-3.3.14.es.po).

Se preservan sus cabeceras de autoría. Se importan una sola vez mediante `drush locale:import-all`; la instalación no depende de que el servidor de traducciones esté disponible. Al actualizar las dependencias hay que actualizar también estas traducciones y su marca de importación.
